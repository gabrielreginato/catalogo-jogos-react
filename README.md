# At Full Steam

Este projeto React consiste em um catálogo online que reúne informações de jogos em promoção da plataforma Steam e as apresenta em um grid
de visualização paginado (6 cards em cada página). Também é possível buscar por um jogo específico inserindo seu título na barra de pesquisa. Os dados são obtidos através da API [Cheapshark](https://apidocs.cheapshark.com/). O projeto também utiliza a biblioteca [Material UI](https://mui.com/).

## Como executar

Para executar o projeto em sua máquina, basta clonar este repositório com o comando ***git clone https://github.com/gabrielreginato/catalogo-jogos-react*** ou baixá-lo através desta página do GitHub. Após isso, é necessário instalar suas dependências com o comando ***npm install*** e, por fim, executar ***npm run dev*** e acessar sua URL (geralmente http://localhost/5173, URL padrão do Vite).
